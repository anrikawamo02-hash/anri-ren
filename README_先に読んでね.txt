3. 既存の ren_base.png／eyes_half.png／eyes_closed.png は触らない。
4. index.htmlとstyle.cssも変更不要。
5. GitHub PagesをiPhoneで再読み込みし、「口パク練習」を1回押して5母音を確認する。もう一度押すと停止して閉じ口へ戻る。
